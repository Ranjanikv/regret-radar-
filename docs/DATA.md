## 5. Injected Synthetic Patterns

1. **Seasonality**:
   - Weekend sales multiplier: `1.55x` base daily volume.
   - Festival season window (days 40–52, simulating Diwali / Navratri peak): `2.40x` demand surge.
2. **Stock-Out Cascades**:
   - Store replenishment operates with minimum reorder thresholds. High festive demand exhausts buffer stock, causing `is_stockout = 1` and recording `missed_demand_units`.
3. **Size & Category Return Skew**:
   - Apparel and Footwear categories exhibit baseline return rates of ~14–28%, compared to <5% for Beauty/Home.
   - Extreme sizes (`XS` and `XXL`) have 2x higher return propensity with reasons `Size too small` and `Size too large`.
4. **Silent Churn Correlation**:
   - Customers subjected to repeated return frictions and stockouts generate high-friction support tickets.
   - Churn probability for the high-risk ticket cohort is **78%**, versus **4%** for satisfied customers.
